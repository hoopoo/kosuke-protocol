# 選択と現在の生活

*不妊治療を経て得たもの*

45歳のとき、不妊治療を経て子どもを授かった。選ばなかった道は、不妊治療を諦めることであったが、私は妻と息子と三人で暮らす人生を選んだ。現在も、妻と息子との三人家族で暮らし、自分の会社を経営している。息子を可愛いと感じ、彼の友人が家に遊びに来ることを楽しいと感じている。これらの要素は、私の現在の生活の中で大きな役割を果たしている。

ただ、時折、今も二人目を持っていたらどうだったかと考えることがある。この思いは、私の心の中に残っている未接続の部分であり、過去の選択と現在の生活が交差する瞬間を感じさせる。45歳のときの選択が、今の私の生活にどのように結びついているのかを考えると、まだ接続しきれていないものがあることに気づく。これが私の人生の一部であり、今後も考え続けるテーマである。
