# 十九歳の合格と、現在の仕事

*別の大学をめぐる仕事と人間関係の問い*

19歳のとき、第一志望の早稲田大学第一文学部に合格し、そこへ進んだ。別の大学への進学がある。

現在は、複数の業界を経験したあと、文章やプロトコルをまとめている。19歳での合格という過去と、この現在とのあいだには、まだ接続しきれていないものが残っている。早稲田大学第一文学部への進学から現在の仕事までを、ひとつの経緯として結ぶ材料はここにはない。

別の大学なら、仕事や人間関係がどう変わったかと考えることがある。別の大学という道は、過去の選択肢としてだけでなく、現在の仕事と人間関係に並ぶ問いとして残っている。答えの定まらないまま、その問いは、文章やプロトコルをまとめる現在のそばにある。
