# 三人の暮らしと、残る問い

*不妊治療を経て子どもを授かり、二人目の治療をやめた後の現在*

45歳のとき、不妊治療を経て子どもを授かった。妻と息子との三人で暮らしている。不妊治療を諦めることも、当時には置かれていた可能性だった。

息子を授かった後には、二人目を目指す治療を続けるかどうかを妻と話し合い、やめた。その後も、二人目を持っていたらどうだったかと考えることがある。

いま、息子を可愛いと感じている。息子の友人が家に遊びに来ることも楽しい。45歳のときに子どもを授かったことと、この家で続く現在の時間を並べて見ることはできる。ただし、そのあいだには、まだ接続しきれていないものが残っている。
