## 2. Contradiction detector

Deterministic polarity pairs with shared-entity / primary trigger↔chosen context:

`落ちた↔入社した`, `不合格↔合格`, `辞退した↔入学した`, `断った↔受けた`, `やめた↔続けた`, `行かなかった↔行った`, `離婚した↔結婚生活を続けた`

On hit: clear Residue / actual secondaries / thesis; `items_to_confirm` + 1 neutral clarification; status `needs_additional_input`; `thesis_deferred_due_to_contradiction=true`.

---

## 3. Confirmation approval guard

`DeepReadingService.confirm(approve)` now raises if:

- material contradiction remains
- vague-branch / `structural_ambiguity`
- v1.0.1 notes still blocking

Invariant: `material_contradiction_count > 0` ⇒ `confirmed_by_user` cannot become true ⇒ Call 2 cannot run.

---

## 4. Unrealized-path modality

First-class `unrealized_path_modality_violation` on Call3Validation.

Detects realized modality (`ことがあった`, `経験があった`, `へ行った`, …) on unchosen / unrealized / CF paths.

Deterministic repair (e.g. `地方の大学へ行くことがあった` → `…へ進む道は選ばなかった`). Blocks publish until clean. **Call 3 prompt not bumped.**

---

## 5. Vague-branch gate

Rejects placeholder period/trigger/chosen/unchosen combinations (特にない / なんとなく / 今の人生 / もっと自由な人生, …).

Status `structural_ambiguity`; Residue cleared; ≤2 clarifications.

---

## 6. Sensitive-domain thesis validation

For health/body/fertility/… (tags or content heuristic): reject unsupported causal / evaluative completion (`ことで楽`, `つながっている`+楽, `良い選択`, …).

Rewrite to coexistence when possible; else defer thesis. Does not block solely for empty thesis.
