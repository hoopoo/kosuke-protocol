# 近所を歩く週末と、残っていた場合

*「残っていたらどうだったか」を、答えのないまま現在に置く*

### 27歳の転職、その後の週末

27歳で転職を決め、新しい会社へ移った。そのときには、今の会社に残ることもあった。現在は新しい会社で働き、週末には近所を歩いている。仕事の場と、近所を歩く週末の時間。その生活のなかに、「残っていたらどうだったか」という問いが置かれている。

残っていた場合の仕事や生活がどのようなものだったかを結びつける材料はない。けれど、27歳で会社を移ったという出来事のあとにも、残ることがありえたという輪郭は消えずにある。新しい会社で働く現在と、近所を歩く週末の現在のそばに、その問いは答えのないまま続いている。過去の決定と現在の生活のあいだには、まだ接続しきれていないものが残っている。
