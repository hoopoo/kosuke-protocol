# 早稲田大学第一文学部から現在まで

*別の大学という道を残したまま、現在までを並べて見る*

19歳のとき、第一志望の早稲田大学第一文学部に合格した。選ばなかった道は、別の大学へ進学することだった。早稲田大学第一文学部という行き先と、別の大学というもう一つの道が、その時点に並んでいる。

現在は、複数の業界を経験したあと、文章やプロトコルをまとめている。19歳での合格と現在とのあいだを直接結びつける材料はない。ただ、合格という過去の一点ののちに、複数の業界を経て文章やプロトコルをまとめる現在がある。そのあいだには、まだ接続しきれていないものが残っている。

別の大学なら、仕事や人間関係がどう変わったかと考えることがある。別の大学での仕事や人間関係を具体的に語ることはできない。それでも、選ばなかった道を残したまま現在を見れば、19歳の合格は過去として閉じきらない。早稲田大学第一文学部への合格と、いま文章やプロトコルをまとめていることを、同じ時間の両端に置いておくことができる。
